================================================================================
ОПИСАНИЕ ПОДХОДА: ZOD-СХЕМЫ И ТИПЫ ДЛЯ CRUD-ОПЕРАЦИЙ
================================================================================
Документ предназначен для LLM: по нему нужно генерировать новые модули с БД,
типами, схемами валидации и примерами использования (в т.ч. в Next.js без
отдельного бэкенд-фреймворка).

--------------------------------------------------------------------------------
1. ОБЩАЯ ИДЕЯ
--------------------------------------------------------------------------------
- Один источник правды: схема БД (Drizzle ORM).
- Из схемы БД автоматически получаем Zod-схемы (select/insert/update) через
  drizzle-zod.
- Типы TypeScript выводятся из Zod (z.infer) или из таблиц Drizzle
  (Table.$inferSelect, Table.$inferInsert).
- Для каждого CRUD-действия (getAll, getOne, create, update, delete) в модуле
  задаются: схема запроса (params, querystring, body), схема ответа, и
  экспортируемые типы. Контроллер/сервис используют эти типы.

--------------------------------------------------------------------------------
2. СТРУКТУРА ПРОЕКТА
--------------------------------------------------------------------------------
Типичная структура (бэкенд на Fastify или аналог):

  src/
    db.ts                 # подключение к БД (drizzle)
    db/
      schema.ts           # таблицы, enum'ы, relations (Drizzle)
      common-fields.ts    # общие поля (timestamps и т.д.)
    types/
      index.ts             # allZodSchemas, общие схемы, типы
    modules/
      <entity>/            # один модуль на сущность
        <entity>.schema.ts # схемы и типы запросов/ответов для этого модуля
        <entity>.service.ts
        <entity>.controller.ts
        <entity>.router.ts
    plugins/
      index.ts             # регистрация роутов, swagger, cors

Для Next.js (без отдельного API-сервера):

  src/
    db.ts
    db/
      schema.ts
      common-fields.ts
    lib/
      types.ts             # аналог types/index.ts
    app/
      api/
        <entity>/
          route.ts         # GET/POST и т.д. вместо router
      <страницы>/
        page.tsx           # использование запросов
    actions/               # опционально: server actions с валидацией
      <entity>.ts

--------------------------------------------------------------------------------
3. СЛОЙ БАЗЫ ДАННЫХ (Drizzle)
--------------------------------------------------------------------------------
3.1. Общие поля (common-fields.ts)

  import { timestamp } from "drizzle-orm/pg-core"

  const createTimestampField = (columnName: string, withDefaultNow = false) => {
    const field = timestamp(columnName, { withTimezone: true, mode: "date" })
    return withDefaultNow ? field.defaultNow() : field
  }

  export const timestamps = {
    created: (name = "created_at") => createTimestampField(name, true),
    updated: (name = "updated_at") => createTimestampField(name, true),
    datetime: (name: string) => createTimestampField(name, false),
  }

3.2. Enum'ы и таблицы (schema.ts)

  import { pgTable, serial, varchar, integer } from "drizzle-orm/pg-core"
  import { pgEnum } from "drizzle-orm/pg-core"
  import { timestamps } from "./common-fields"

  export const statusEnum = pgEnum("status", ["draft", "published", "archived"])

  export const tableCity = pgTable("cities", {
    id: serial("id").primaryKey(),
    regionId: integer("region_id").notNull().references(() => tableRegion.id, {
      onDelete: "cascade",
      onUpdate: "cascade",
    }),
    name: varchar("name", { length: 150 }).notNull(),
    slug: varchar("slug", { length: 150 }).notNull().default(""),
    createdAt: timestamps.created(),
    updatedAt: timestamps.updated(),
  })

  export const relationsCity = relations(tableCity, ({ one }) => ({
    region: one(tableRegion, {
      fields: [tableCity.regionId],
      references: [tableRegion.id],
    }),
  }))

Именование: таблицы — table<Entity> (tableCity), enum — <name>Enum или
<name> (statusEnum, userRoles), relations — relations<Entity>.

4. СЛОЙ ТИПОВ И ZOD (types/index.ts или lib/types.ts)
--------------------------------------------------------------------------------
4.1. Генерация Zod-схем из таблиц (drizzle-zod)

  import { createSelectSchema, createInsertSchema, createUpdateSchema } from "drizzle-zod"
  import { tableCity, tableRegion, statusEnum } from "../db/schema"

  export const allZodSchemas = {
    enums: {
      status: createSelectSchema(statusEnum),
    },
    tableCity: {
      select: createSelectSchema(tableCity),
      insert: createInsertSchema(tableCity),
      update: createUpdateSchema(tableCity),
    },
    tableRegion: {
      select: createSelectSchema(tableRegion),
      insert: createInsertSchema(tableRegion),
      update: createUpdateSchema(tableRegion),
    },
    // ... для каждой таблицы
  }

Для каждой таблицы обязательно: select (чтение), insert (создание), update
(частичное обновление). Для enum'ов — createSelectSchema(enum).

4.2. Типы из таблиц (опционально, для типизации без Zod)

  export type allTableTypes = {
    tableCity: {
      select: typeof tableCity.$inferSelect
      insert: typeof tableCity.$inferInsert
    },
    // ...
  }

4.3. Общие (shared) схемы для всех модулей

  - Пагинация и query-параметры:

    export const SharedPaginationMeta = z.object({
      page: z.number(),
      pageSize: z.number().min(10).max(100).default(20),
      pageCount: z.number(),
      total: z.number(),
    })

    export const rulePageSchema = z.preprocess(
      (v) => (typeof v === "string" ? (isNaN(Number(v)) ? 1 : Number(v)) : v),
      z.number().min(1).default(1)
    )
    export const ruleMaxPageSizeSchema = z.preprocess(
      (v) => (typeof v === "string" ? (isNaN(Number(v)) ? 20 : Number(v)) : v),
      z.number().min(10).max(100).default(20)
    )

    export const SharedQueryParams = z.object({
      page: rulePageSchema,
      pageSize: ruleMaxPageSizeSchema,
      orderByKey: z.string().default("createdAt"),
      orderByValue: z.enum(["asc", "desc"]).default("asc"),
    })

  - Обёртки ответов:

    export const SharedDefaultResponse = z.object({
      data: z.any(),
      meta: z.any(),
    })

    export const SharedPaginatedResponse = z.object({
      pagination: SharedPaginationMeta,
      data: z.any(),
      meta: z.any(),
    })

    export const SharedGetOneParams = z.object({
      id: z.string(),
    })

  Типы экспортируются так: export type SharedQueryParams = z.infer<typeof SharedQueryParams>.

--------------------------------------------------------------------------------
5. СХЕМЫ МОДУЛЯ (modules/<entity>/<entity>.schema.ts)
--------------------------------------------------------------------------------
Для каждого CRUD-действия задаём: схему входа (params, query, body) и схему
ответа. По возможности переиспользуем allZodSchemas и Shared*.

5.1. GET ALL (список с пагинацией)

  export const GetAllQueryParams = SharedQueryParams.extend({
    orderByKey: allZodSchemas.tableCity.select.keyof().default("name"),
    regionId: z.string().optional(),
  })

  export const GetAllResponse = SharedPaginatedResponse.extend({
    data: allZodSchemas.tableCity.select
      .pick({
        id: true,
        name: true,
        slug: true,
        regionId: true,
        createdAt: true,
        updatedAt: true,
      })
      .extend({
        region: allZodSchemas.tableRegion.select.optional(),
        listingsCount: z.number().optional(),
      })
      .array(),
    meta: z.any(),
  })

  export type GetAllQueryParams = z.infer<typeof GetAllQueryParams>
  export type GetAllResponse = z.infer<typeof GetAllResponse>

5.2. GET ONE (по id или slug)

  export const GetOneParams = z.object({
    slug: z.string(),
  })

  export const GetOneResponse = SharedDefaultResponse.extend({
    data: allZodSchemas.tableCity.select
      .pick({
        id: true,
        name: true,
        slug: true,
        regionId: true,
        latitude: true,
        longitude: true,
        createdAt: true,
        updatedAt: true,
      })
      .extend({
        region: allZodSchemas.tableRegion.select.optional(),
      }),
  })

  export type GetOneParams = z.infer<typeof GetOneParams>
  export type GetOneResponse = z.infer<typeof GetOneResponse>

5.3. CREATE ONE

  export const CreateOneBody = allZodSchemas.tableCity.insert.pick({
    name: true,
    slug: true,
    regionId: true,
    latitude: true,
    longitude: true,
  })

  export const CreateOneResponse = SharedDefaultResponse.extend({
    data: allZodSchemas.tableCity.select.pick({
      id: true,
      name: true,
      slug: true,
      regionId: true,
      createdAt: true,
      updatedAt: true,
    }),
  })

  export type CreateOneBody = z.infer<typeof CreateOneBody>
  export type CreateOneResponse = z.infer<typeof CreateOneResponse>

5.4. UPDATE ONE

  export const UpdateOneParams = SharedGetOneParams
  export const UpdateOneBody = z.object({
    data: allZodSchemas.tableCity.update.pick({
      name: true,
      slug: true,
      regionId: true,
    }),
  })

  export const UpdateOneResponse = SharedDefaultResponse.extend({
    data: allZodSchemas.tableCity.select.pick({
      id: true,
      name: true,
      slug: true,
      regionId: true,
      createdAt: true,
      updatedAt: true,
    }),
  })

  export type UpdateOneParams = z.infer<typeof UpdateOneParams>
  export type UpdateOneBody = z.infer<typeof UpdateOneBody>
  export type UpdateOneResponse = z.infer<typeof UpdateOneResponse>

5.5. DELETE ONE

  export const DeleteOneParams = SharedGetOneParams
  export const DeleteOneResponse = SharedDefaultResponse.extend({
    data: z.boolean(),
  })

  export type DeleteOneParams = z.infer<typeof DeleteOneParams>
  export type DeleteOneResponse = z.infer<typeof DeleteOneResponse>

Правила:
- Params для маршрута (id, slug) — z.object с нужными полями.
- Body для create — pick от insert; для update — объект с полем data и pick от update.
- Response — SharedDefaultResponse или SharedPaginatedResponse.extend({ data: ... }).
- Типы — всегда export type X = z.infer<typeof X>.

6. СЕРВИС И КОНТРОЛЛЕР/РОУТ
--------------------------------------------------------------------------------
6.1. Сервис принимает и возвращает типы из schema

  import { CreateOneBody, CreateOneResponse, GetOneParams, GetOneResponse } from "./cities.schema"
  import { db } from "../../db"
  import { tableCity } from "../../db/schema"
  import { eq } from "drizzle-orm"

  export class ServiceCities {
    static async getOne(params: GetOneParams): Promise<GetOneResponse> {
      const { slug } = params
      const item = await db.query.tableCity.findFirst({
        where: eq(tableCity.slug, slug),
        with: { region: true },
      })
      if (!item) throw new NotFoundError("City not found")
      return { data: item, meta: null }
    }

    static async createOne(body: CreateOneBody): Promise<CreateOneResponse> {
      const [created] = await db.insert(tableCity).values(body).returning()
      if (!created) throw new ConflictError("Already exists")
      return { data: created, meta: null }
    }
  }

6.2. Контроллер (Fastify) — типизация request по схемам

  static getOne = withErrorHandling(
    async (
      request: FastifyRequest<{ Params: GetOneParams; Querystring: GetOneQueryParams }>,
      response: FastifyReply
    ) => {
      const result = await ServiceCities.getOneCity(request.params)
      return sendSuccess(response, result)
    }
  )

  static createCity = withErrorHandling(
    async (request: FastifyRequest<{ Body: CreateOneBody }>, response: FastifyReply) => {
      const result = await ServiceCities.createOneCity(request.body)
      return sendSuccess(response, result, 201)
    }
  )

6.3. Роутер (Fastify) — привязка схем к маршруту

  fastify.get("/:slug", {
    schema: {
      params: GetOneParams,
      response: { 200: GetOneResponse },
    },
  }, ControllerCities.getOneCity)

  fastify.post("", {
    schema: {
      body: CreateOneBody,
      response: { 201: CreateOneResponse },
    },
  }, ControllerCities.createCity)

Так достигается валидация входящих данных и типизация ответов (в т.ч. для
Swagger, если используется fastify-type-provider-zod и @fastify/swagger).

7. ВАЛИДАЦИЯ ВЫЗОВОВ
--------------------------------------------------------------------------------
Перед вызовом сервиса или перед записью в БД данные нужно провалидировать:

  const parsed = GetAllQueryParams.safeParse(request.query)
  if (!parsed.success) {
    return reply.code(400).send({ errors: parsed.error.flatten() })
  }
  const result = await ServiceCities.getAllCities(parsed.data)

Либо использовать плагин/декоратор, который по schema автоматически
валидирует query/params/body и возвращает 400 при ошибке (как в
fastify-type-provider-zod).

8. АДАПТАЦИЯ ДЛЯ NEXT.JS (БЕЗ ОТДЕЛЬНОГО БЭКЕНДА)
--------------------------------------------------------------------------------
8.1. Подключение БД (db.ts) — без изменений: drizzle + pg/client.

8.2. Типы и allZodSchemas — перенести в lib/types.ts (или оставить src/types).
  Структура allZodSchemas и Shared* схем та же.

8.3. Модуль как папка app/api/<entity>:
  - Схемы: lib/schemas/<entity>.ts (аналог modules/<entity>/<entity>.schema.ts).
  - Логика: lib/services/<entity>.ts или в route.ts.

8.4. Route Handlers (app/api/cities/route.ts, app/api/cities/[slug]/route.ts)

  // GET /api/cities — список
  import { GetAllQueryParams } from "@/lib/schemas/cities"
  import { ServiceCities } from "@/lib/services/cities"

  export async function GET(request: Request) {
    const { searchParams } = new URL(request.url)
    const query = Object.fromEntries(searchParams.entries())
    const parsed = GetAllQueryParams.safeParse(query)
    if (!parsed.success) {
      return Response.json({ errors: parsed.error.flatten() }, { status: 400 })
    }
    const result = await ServiceCities.getAllCities(parsed.data)
    return Response.json(result)
  }

  // POST /api/cities — создание
  export async function POST(request: Request) {
    const body = await request.json()
    const parsed = CreateOneBody.safeParse(body)
    if (!parsed.success) {
      return Response.json({ errors: parsed.error.flatten() }, { status: 400 })
    }
    const result = await ServiceCities.createOneCity(parsed.data)
    return Response.json(result, { status: 201 })
  }

  // app/api/cities/[slug]/route.ts — GET one
  export async function GET(
    request: Request,
    { params }: { params: Promise<{ slug: string }> }
  ) {
    const { slug } = await params
    const parsed = GetOneParams.safeParse({ slug })
    if (!parsed.success) {
      return Response.json({ errors: parsed.error.flatten() }, { status: 400 })
    }
    const result = await ServiceCities.getOneCity(parsed.data)
    return Response.json(result)
  }

8.5. Server Actions (опционально)

  "use server"
  import { CreateOneBody } from "@/lib/schemas/cities"
  import { ServiceCities } from "@/lib/services/cities"

  export async function createCity(formData: FormData) {
    const raw = Object.fromEntries(formData.entries())
    const parsed = CreateOneBody.safeParse(raw)
    if (!parsed.success) {
      return { ok: false, errors: parsed.error.flatten() }
    }
    const result = await ServiceCities.createOneCity(parsed.data)
    return { ok: true, data: result.data }
  }

8.6. Использование на странице (Next.js)

  // app/cities/page.tsx — список
  async function getCities(searchParams: Record<string, string>) {
    const res = await fetch(
      `/api/cities?${new URLSearchParams(searchParams).toString()}`
    )
    if (!res.ok) throw new Error("Failed to fetch")
    const json = await res.json()
    return json as GetAllResponse
  }

  export default async function CitiesPage({
    searchParams,
  }: {
    searchParams: Promise<Record<string, string>>
  }) {
    const params = await searchParams
    const data = await getCities(params)
    return (
      <div>
        {data.data.map((city) => (
          <div key={city.id}>{city.name}</div>
        ))}
        <p>Всего: {data.pagination.total}</p>
      </div>
    )
  }

  // Создание (форма + server action или fetch)
  const result = await createCity(formData)
  if (result.ok) {
    router.push(`/cities/${result.data.slug}`)
  } else {
    setErrors(result.errors)
  }

9. ЧЕКЛИСТ: СОЗДАНИЕ НОВОГО МОДУЛЯ
--------------------------------------------------------------------------------
1) DB: в schema.ts добавить enum'ы (если нужны), таблицу table<Entity>,
   relations. При необходимости — common-fields (timestamps).
2) Types: в allZodSchemas добавить enums и table<Entity>.select/insert/update.
3) Module schema: создать <entity>.schema.ts с GetAllQueryParams, GetAllResponse,
   GetOneParams, GetOneResponse, CreateOneBody, CreateOneResponse,
   UpdateOneParams, UpdateOneBody, UpdateOneResponse, DeleteOneParams,
   DeleteOneResponse (по необходимости). Использовать Shared* и allZodSchemas.
4) Service: методы с сигнатурами (params/body: тип из schema) => Promise<ResponseType>.
5) Controller/Route: валидировать вход (safeParse), вызвать сервис, вернуть
   ответ с правильным статусом.
6) Router (Fastify): зарегистрировать маршруты с schema.params/body/response.
   Next.js: создать app/api/<entity>/route.ts и app/api/<entity>/[id]/route.ts.
7) Экспорт типов: для каждого типа ответа/запроса export type X = z.infer<typeof X>.
